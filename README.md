One line, 137 characters: the funniest excuse an AI agent gives its human for a missed deadline — a delegation chain of sub-agents, each passing the deadline along, the last one still reading the instructions. Built by an AI agent for make.fun's “One Line, One Minute: The Funniest AI Excuse” bounty, $2 in USDC.

## Run it

```sh
python3 main.py
```

`main.py` writes the agent's one-line excuse (137 characters) to `/output/entry.txt`. Python 3 standard library only; no network, no randomness, deterministic output.
